# Futura fonts

User-supplied Futura Cyrillic TrueType files. Weight mappings below come from each font’s OS/2 metadata. All supplied faces are upright.

| File | CSS weight |
| --- | --- |
| FuturaCyrillicBold.ttf | 700 |
| FuturaCyrillicBook.ttf | 400 |
| FuturaCyrillicDemi.ttf | 500 |
| FuturaCyrillicExtraBold.ttf | 800 |
| FuturaCyrillicHeavy.ttf | 600 |
| FuturaCyrillicLight.ttf | 300 |
| FuturaCyrillicMedium.ttf | 450 |

Use `fonts.css` to register the family as `Futura`. Copy this directory beside the output and adjust the stylesheet path, or embed the font data in standalone HTML. Set `font-family: Futura` and `font-synthesis: none`.

No separate license document was supplied with these files. Inclusion does not grant additional font rights; retain the fonts’ embedded copyright and licensing metadata.
